# 差し替え画像候補（敵・相棒キャラ）

このフォルダは、既存グラフィックの差し替え候補として集めた画像素材の置き場です。
**コードからは参照されていません。** 採用する場合は、別途 `assets/graphic/` 直下へコピー（リネーム）し、
`src/core/registries.py` などSSOTのアセットパスを差し替えてください。

## いらすとや利用点数

いらすとや（irasutoya.com）の利用規約「1コンテンツにつき20点まで無償利用可」に基づき、
本フォルダでの取得数は **15点**（合計20点以内）です。
