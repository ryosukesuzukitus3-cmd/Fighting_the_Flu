# 移動速度・レーザーキーの試遊版（2026-09-20）

## 目的と範囲

ユーザーの試遊で速度と難度の印象を確認するための中間版。
難所追加・回復制限・チェックポイントの提案は、この試遊の反応を受けてから検討する。

- 初期移動速度: 280 → 140px/秒。
- 速度強化: 3段階、初期速度の25%（35px/秒）ずつ加算。140 → 175 → 210 → 245px/秒。
- レーザーの既定キー: B。強化画面: V。既存の任意キー設定は引き続き保持する。
- この端末の保存済み設定ではレーザーと強化がVで重複していたため、レーザーのみBへ変更。音量等は保持。
- 自動操作の移動予測も実ゲームと同じ基礎速度定数を参照。
