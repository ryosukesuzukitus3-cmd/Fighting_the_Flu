## まず結論

先輩の主軸は **ヤニねこ**。横着、目先の快適さ、都合のよい自己弁護、すぐ表情に出る損得が笑いになる。
**ヤクねこ**は別人であり、先輩に借りるのは不意に会話が途切れるような不穏さだけ。
旧稿の「臨床的な管理外」「薬物知識の解説」「いいことを言う→全部想像と撤回」は、この区別を曖昧にしていた。

「にょ」や薬の姿、澤口との関係は本作独自の設定。原作の台詞やエピソードを移植するのでなく、行動と会話の組み立てを参考にする。

## 漫画からの観察（自筆の短い読書メモ）

### M01: 小さな欲と、その場で破綻する理屈

灰の処理を横着する動き、生活費の見通しより目先の欲に負ける展開が見える。困った瞬間の深刻さと、都合がよくなるとすぐ機嫌が戻る落差が大きい。読者への長い教訓ではなく、表情・姿勢・直後の行動がオチを担う。

**本作での応用判断:** 先輩は休む場所を欲しがり、障害物をどかす手間を惜しんで自分まで飛ばされる。本人は真面目に楽をしようとしているため、澤口の短い反応だけで成立させる。

### M02: 身内にだけ見せる見栄と遠慮のなさ

妹に対して格好をつけたい気持ちがある一方、生活の雑さがすぐ露呈する。姉妹の言葉は辛辣でも、関係そのものを逐一説明しない。掃除など目前の面倒を大きく感じ、別の喜びへ簡単に流される。

**本作での応用判断:** 「先輩だから導く」のでなく、先輩だから手柄を欲しがる。澤口に素直に礼を言われると、即座に格言を返さず一拍黙る。

### M03: 重い状態から日常へ戻す距離感

中心人物はヒキねこ。ヤニねこの通常の性格資料とは区別する。内面の沈みを説明した後、誰かが戻ってきて生活のやり取りが再開することで着地している。重い言葉だけで話を閉じない構成が参考になる。

**本作での応用判断:** 結末を人生論でまとめず、水・休息・連絡といった行動に戻す。特定の場面や台詞は移植しない。

### M04: 善意まで自分の感覚で実行する

本人には片付けや親切のつもりでも、相手には迷惑になる。そのずれを説明で処理せず、相手の顔と次の行動で見せる短編がある。仕事の決まりと目先の欲求の衝突も、口先の立派さより行動が先に出る。

**応用判断:** 先輩の横着は「本当は全てを見通した演技」にはしない。普段の欠点を残したまま、救出の一度だけ損を引き受ける。

### P02 / P03: 出版社が紹介する魅力

担当編集は、欠点を含めた人間らしさを魅力として紹介している（P02）。
出版社の第2巻CM記事は、妹やヤクねこを含む周囲との日常を作品紹介の中心に置く（P03）。
「本当は完璧な相談役」へ美化するより、困ったところも相手に引き受けてもらう人物が合う、というのが今回の応用判断。

## 公式設定と、出演者の読みを分ける

### A01: 公式人物紹介の事実

ヤニねこは佐藤ヤニ子、21歳の猫獣人。ヤクねこは越司丸益子、20歳で、ヤニねこを先輩として慕う別の人物。
前者の生活優先の性格と、後者の不穏な背景を「薬物キャラ」一つへ混ぜない。

### I01: ヤニねこ役の解釈

煙草以外への淡白さ、失敗しても目先の安堵へ戻る感じ、妹への姉らしい顔を見せたい気持ちが語られる。
周囲も含め欠点があるが憎めない、という読み。これは演者の解釈であり、作者が指定した作劇公式ではない。

**応用:** 感情を隠し続ける冷静な薬ではなく、欲求が顔と態度に出る薬にする。

### I02: ヤクねこ役の解釈

根底の真面目さ、相手によって変わる会話の温度、過去を含む複雑さが語られる。
奇行だけを並べる人物像ではない。常に薬物を匂わせる必要もない。

**応用:** 不穏な一言はごく少数。旧稿の「合法」「毒の抜き方」「経験談」を常用する仕組みを廃止する。

### I03: いもうとこ役の解釈

辛辣さと身内への情は両立する。周囲への反応や間が会話の面白さを支える、という読み。

**応用:** 澤口は説明係だけでなく、先輩の不始末を助ける側にも回る。互いに突っ込みながら隣を空ける関係を作る。

### I04: アルねこ役の解釈

本人は真剣でも外からは可笑しい、その演じ方と可愛い外見の働きが参考になる。
アルねこの飲酒中心の性格を先輩へ追加する根拠にはしない。

## 本作での改稿方針と実装対応

| 場面 | 旧稿の問題 | 今回の構成 |
|---|---|---|
| 出会い | 担当・管理外・合法など設定説明の連打 | 寝床争いから横に居つく。朝に殻が消えても効き目が残ることだけ先に示す |
| 1→2 | 良い話を自分で撤回する定型 | 横着な解熱圧で反動。澤口が助け、借りが一つできる |
| 2→3 | つらい告白をさらに採点する先輩 | 気の利いたことを言えず、一緒に座る |
| ボス戦 | 格言・自己分析が多い | 目の前の弾や自分の手柄への短い反応 |
| ブラックホール | 長い物理談義、短距離の蹴り | 全残力を両手に集める解熱圧。澤口を画面外へ押し出し、自分は反動で落ちる |
| 再会 | 未解決物理を都合よく解決して復活 | 序盤の「残る効き目」を回収。残効の姿で最後の支援。澤口自身が助けを求める |
| 決着 | 一人でまた身代わりになる印象 | 二人で踏ん張り、澤口が最後のビームを撃つ |
| 朝 | 人生が変わったとの抽象的宣言 | 現実の相手に頼みを送り、水を飲み休む。薬はしゃべらない |
