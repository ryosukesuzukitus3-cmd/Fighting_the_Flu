# インフルとの死闘 — 現行フル台本（実装＋演出・ブラッシュアップ入力用）

> **この文書の目的**：現行ゲームで実際に流れるセリフ・ナレーションに加え、コードにしか無い**演出・音・ゲーム動作**（「ここで重低音」「ここで画面シェイク」等）を統合した、**漏れの無い一本の台本**。ストーリーラインのブラッシュアップ入力として使う。
>
> **出典（SSOT）**：セリフ＝`src/story/script.py` ／ 話者＝`src/story/speakers.py` ／ 音＝`src/story/aliases.py`＋各ステージ JSON＋`src/scenes/game/config.py` ／ ボス挙動＝`src/entities/enemies/boss.py` ／ 演出＝各 `src/scenes/*`。
>
> **凡例**：
> - `【演出】`＝画面・カメラ・エフェクト。`【音】`＝BGM/SE。`【動作】`＝ゲームプレイ挙動。
> - `[補足]`＝コードに明記が無く、本台本作成者が実装スプライト等から補った推定情報（ブラッシュアップ時に確定してよい）。
> - 話者記号：**澤**＝澤口修平／**先輩**＝カロナール先輩／**先輩+**＝カロナール先輩・薬効最大／**？？？**＝正体不明の声／**N**＝ナレーション／**SYS**＝システム表示。

## 0. ログライン

インフルエンザで高熱にうなされた**澤口修平（31）**が、発熱夢の中で〈ウイルス／ネットミーム／婚活要塞／将棋AI／そして自分自身の"投了癖"〉と戦い、喋る解熱鎮痛剤**カロナール先輩**と凸凹バディを組んで、一晩かけて「まだ投了しない」と決め直す、横スクロールシューティング。

- **トーン**：バカゲー×シリアスの二層。表面はふざけた命名とツッコミ漫才、芯は「体調不良時に増幅する自己否定との対話」。
- **中心テーマ**：先輩は人生を解決しない。ただ、**もう一手指す時間**を作ってくれる。ラスボスを倒すのは先輩ではなく澤口自身。エンディングで現実の問題は何も片付いていない。それでも澤口は「投了していない」状態に戻る。
- **バディ・アークの核**：先輩＝鎮痛剤ゆえ**朝には溶けて消える**。塩対応・不干渉は「どうせ消える自分を深入りさせない予防線」。物語はそのルールを破って、最後まで横にい続ける話。

## 1. 登場人物

### 澤口修平（プレイヤー機体）
- 31歳・独身・大手メーカー勤務。将棋有段者、英検2級、物理学修士。肩書だけは戦えそうなのに、熱・SNS・婚活・自己否定に押されている。
- 口調：通常語尾。皮肉屋・自嘲的だが、芯に頑固さ。決めゼリフ「**まだ投了していない**」。
- `[補足]` スプライトはサングラスの男性の顔（`graphic/sawaguchi_49_64.png`）。機体として画面を移動し撃つ。

### カロナール先輩（随伴キャラ／相棒）
- 喋る解熱鎮痛剤。序盤から澤口機の横に並ぶ支援機。態度はでかいが火力は低い。
- 口調：語尾**「にょ」**（だ→だにょ、よ→にょ、ぬ→にょ）。**短くドライに**保つ（長台詞＋にょ連発は禁）。口癖**「管理外だにょ」**＝解熱以外を臨床的に拒む。
- 裏設定：鎮痛剤なので**朝には溶けて消える**。塩対応は「消える自分の予防線」。
- `[補足]` スプライトは緑のカプセル錠剤（顔アイコン `portrait_karonaru_dummy.png`）。被弾すると一時撤退し、また戻る。
- **強化系統4種**（下段スロット）：HP UP／解熱弾／補給／マグネット。

### カロナール先輩・薬効最大（最終決戦の復帰形態）
- 最終盤で「薬効発現」して復帰する強化形態。高速の白金貫通弾。バディ・アークの回収点。
- `[補足]` 白〜金に輝くカプセル（`portrait_karonaru_max_dummy.png`）。

## 2. ゲーム構造・UI・演出の共通言語

ブラッシュアップ時に「どのタイミングで何が出るか」を把握するための共通語彙。

### 進行の骨格（STORY_BEATS の並び）
```
タイトル →（ゲームスタート）→ プロローグ会話（発熱夢＋ブリーフィング）
  →〔初回のみ〕対話型チュートリアル「準備運動」
  → 第一章プレイ → ボス戦（悪寒大王インフルX）
  → 幕間 1→2 → 第二章プレイ → ボス戦（ブロリー→超サイヤ人ブロリー）
  → 幕間 2→3 → 第三章プレイ → ボス戦（マッチング・ゼロ）
  → 【承認欲求ブラックホール】（先輩の自己犠牲＝喪失）
  → 幕間 3→4（先輩不在）→ 第四章プレイ
  → ラスボス戦：藤井竜王 Form1 → 赤眼の真・藤井四段 Form2
     → 投了王サワグチ Form3（最終決戦フルシーケンス：フェイクアウト→投了勧告→先輩復帰→抗反芻→終局）
  → エピローグ（朝）→ ゲームクリア → エンドロール → ポストクレジット
```

### 会話パネルの種別（見分け）
- **全画面カットシーン**（プロローグ・幕間・エピローグ）：立ち絵＋タイプライター表示、ENTERで送り。
- **戦闘中パネル**（画面下・顔アイコン付き・固定2行サイズ）：
  - 赤枠＝ボス登場セリフ（ENTER送り）／紫枠＝戦闘中セリフ（自動送り）／青枠＝撃破後・味方寄り。
- **中央バナー**：章名／ALERT／BOSS名／FIGHT!／覚醒・投了勧告 等のシステム表示。

### 中央バナー・演出の一覧（戦闘導入〜最終）
- **章名バナー**（3秒）：例「第一章：発熱回廊」。
- **ALERT**（2秒）：`！！ALERT！！` 赤点滅＋画面赤フラッシュ。ボス出現予告。`【音】SE_ALERT`。
- **BOSS名バナー**（2.5秒）：`── BOSS ──` ＋ボス名。`【音】ボス戦BGMへ切替`。
- **FIGHT!**（1.2秒）：`【音】fight.wav`。以後戦闘開始。
- 形態遷移・最終決戦の専用バナー：**覚醒／TRUE FINAL BOSS／投了勧告／薬効発現／HP全回復／投了勧告・終局／LAST CHANCE**（各シーンで後述）。

### fx 語彙（カットシーンのページに付く演出タグ）
`shake`＝画面シェイク／`red_noise`＝赤いノイズ（発熱）／`white_particle`＝白い光の粒子（先輩の顕現・溶解）／`glitch`＝グリッチ（SNS汚染の予兆）／`blackhole`＝重い揺れ＋渦。

### プレイヤー武器・強化（グラディウス式スロット）
- **上段（自機）**：MAIN UP（RAPID1→RAPID2→WIDE→WIDE+→**MEDIC**→MAX）／HOMING（と金＝将棋の成り駒がホーミング）／LASER（チャージレーザー）／SPEED。
- **下段（先輩）**：HP UP／解熱弾／補給／マグネット。
- **アイテム**：`W`（黄）＝ウェポン在庫+1（取得後、選択画面で強化先を選ぶ）／`+`（緑）＝HP回復。
- `[補足]` MEDIC 段は回復寄りのメイン。「と金」ホーミングは将棋モチーフの一貫。

### 道中の敵ロスター（各章に配置・`data/stages/*.json`）
バイキン（直進）／タケシ（波打ち接近）／パチェモン／クローラー（地形を這う）／砲台（turret）／ブロリー系雑魚（接近して高速突進・粒子砲）／咳スプレー（弾幕）／大型残骸（割れて破片化）／胞子分裂体（倒すと分裂）／**ビリー**（各章1体の中ボス格・撃破でウェポン報酬。登場/撃破時にガチムチ語録バークをランダム表示——登場:「ん？」「いいゾ〜これ」「やりますねぇ！」「ファッ！？」／撃破:「お前のことが好きだったんだよ！」「あーもうめちゃくちゃだよ」＋SE「アｯー♂」）。破壊可能ゲート／ウェポンゲート／ボスゲート（到達でボス戦へ）。

### ボスの共通ギミック（3種）
- **shield（周期シールド＋反撃）**：シールド展開中は無敵＋強攻撃、解除中(6秒)が大ダメージのチャンス、展開(3秒)。→ 悪寒大王インフルX／藤井竜王Form1。体幹はシールド解除中のみ削れる。
- **weakpoint（装甲＋弱点露出）**：体幹（旧装甲）がある間は被ダメ無効、削り切ると弱点露出(5秒)で**被ダメ2倍**。→ ブロリー／赤眼の真・藤井四段Form2。
- **turrets（砲台要塞連動）**：砲台を召喚、健在中は本体ほぼ無敵、**全砲台撃破でスタン(4秒・被ダメ2倍)**。→ マッチング・ゼロ。S3 の子機は**サクラ**（マッチングアプリ風の円形プロフィールアイコン、ラベル「サクラ xN」）。加えて**本体の陰に1機**が隠れ、貫通/レーザーでないと届かない。**最後の1機を撃破した瞬間にサクラ「けど、けれどね……」**（撃破後のフル文への前フリ）。

### バトルシステムv2（体幹・体温・持ち駒・症状悪化）
- **体幹ゲージ**：ボスHPバー直上の金色バー。武器で削り切ると**ダウン**＝頭上「BREAK!!  DAMAGE UP」（**S4のみポップアップ「王手！！」＋駒音**）。被ダメ2倍・行動停止の撃ち込みチャンス。レーザーが最も削れる。超サイヤ人ブロリー（ギミック無し形態）も体幹で攻略できる。Form3（投了王）は対象外。
- **体温計（HUD）**：撃つと36.5→39.9℃へ上昇、上限で**「熱暴走！！」**＝しばらくメイン/レーザー射撃不可（ホーミングは可）。初回のみ先輩バーク（「撃ちすぎだにょ。用法・用量にょ。」／「熱は下げるもんだにょ。上げてどうするにょ。」）。**先輩の解熱弾Lvで冷却が速くなる**（解熱鎮痛剤の面目躍如）。ボスダウン中は冷却2倍＝ダウン中は全部撃ってよい。
- **持ち駒（HUD）**：コンボ達成で歩/金/龍を獲得（最大3）。**Bキーで「打つ」**＝弾消し＋全体ダメージ＋ボス体幹へ大ダメージ（シールド貫通）。ポップアップ「「歩」、打つ！」＋駒音。S4ボスの持ち駒打ちとプレイヤーが対になる。
- **症状悪化**：ボス戦が長引くと赤オーラが強まりポップアップ**「症状悪化」**、攻撃間隔が最大1.4倍まで圧縮（Form3対象外）。待ち戦法（熱温存）への対抗。

### SCENE 025｜対話型チュートリアル「準備運動」〔初回のみ〕
**【動作】** ブリーフィング直後・STAGE1直前に初回のみ挿入（専用の軽量プレイアブルシーン）。カロナール先輩が澤口をコーチ。星空下地の練習場（`PRACTICE`表示）。勝敗どちらでも進む・**ゲームオーバー無し**。キー表記はキーバインド設定に追従。

- **先輩**：……で、澤口。いきなり本番は、きついにょ。
- **先輩**：準備運動、していくかにょ？　`【動作】選択肢：はい、する／いや、いい`

**③ 撃つ**（`【演出】バナー「準備運動：射撃」＋「{射撃}キーで撃て（押しっぱなしで連射）」`。数発撃つまで保持）
