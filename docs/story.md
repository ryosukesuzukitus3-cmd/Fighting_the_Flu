> **この文書の役割**: 脚本に関する唯一のドキュメント。①正典（何を守り、どこまで攻めてよいか）②登場人物・構造 ③現行ゲームの全セリフ＋演出注記、を1本に統合したもの。旧 `story_canon.md`／`story_bible.md`／`story_rework_stubborn.md` を置き換える（経緯は git 履歴参照）。
>
> **編集の運用**: この文書は**制作者（ユーザー）が直接編集してよい**。編集後は、エージェントが「セリフ・ストーリーを変更するとき」チェックリスト（CLAUDE.md／AGENTS.md）に従って `src/story/script.py` へ反映する。逆にコード側でセリフを変えたら、この文書の該当箇所も同じPRで更新する（**セリフ実装の SSOT は `src/story/script.py`、本書は編集・レビューの入力点**）。
>
> **表記の約束**: ゲーム内キャラクターは「澤口修平」。モデルとなった実在人物への言及は「**S口**」とぼかし表記。人物像はフィクション・誇張・制作者のネタ的解釈が混在する**設定資料**であり、実在の個人の正確な記述ではない。
>
> **凡例**: `【演出】`＝画面・カメラ・エフェクト。`【音】`＝BGM/SE。`【動作】`＝ゲームプレイ挙動。`[補足]`＝コードに明記が無い推定情報。`／`＝同一ページ内の改行。話者記号: **澤**＝澤口修平／**先輩**＝カロナール先輩／**先輩+**＝薬効最大／**？？？**＝正体不明の声／**N**＝ナレーション／**SYS**＝システム表示。

## 1. 正典（弄りの線引き・保持必須ネタ）

### 前提

- このゲームは LINE グループ「アラスカ」の仲間内で楽しむ贈り物で、**S口本人がプレイする**。
- 弄りは「**本人が一番笑える公開処刑**」の線。晒し上げではなく、本人が読んで笑える誇張・様式化に留める。
- **本人がヒーローとして気持ちいい構図は不可侵**。ラスボス（＝自分の内なる敵）を倒すのは先輩ではなく澤口自身、という構造を崩す変更は禁止。
- ゲーム化の発端は、普段体調を崩さない S口が珍しくインフルでダウンした実話。インフルという器を外してよい言質はあるが、先輩（解熱鎮痛剤＝朝には溶けて消える）のアークが器に依存するため**維持を推奨**。

### モデル人物像（S口・ネタ設定資料）

- **根性は本物**: 鳥人間サークルで同期20人以上がどんどん辞めていく中、最後の2人まで残った片方。設計主任として最後までやり抜いた。今もOBとして技術相談グループで（ちょっと頼りないものの）後輩をサポートしている。
- ただし、**くそ頑固で融通が利かない**。対人能力が激弱＋相当忘れっぽいのが相まって、周りの助言・反応をうまくフィードバックできず、改善されない、あるいは激遅（**5回くらい言わないと伝わらない**。中途半端な改善に終始したり、改善が数年スパンだったり）。これが周りをいらつかせている。
- 「根性」の実態は**自分勝手な責任感**。周りから求められる責任感ではなく、自分が考える役割への、思い込み要素強めの責任感。対人スキルの低さと白黒思考などの偏った思考からそうなっている。
- メーカー技術者。数学・物理が得意、将棋もかなり強い——が、全て趣味レベル止まりなのが少し悲しい、という自虐込み。英語・国語が壊滅、日常生活壊滅。風呂は2日に1回＋洗濯苦手＝基本臭い（ネタ枠）。
- 変なこだわり: 婚前交渉NG・処女厨・年上NG・**白黒つけたがる**・前提を疑わない。
- **婚活は挑戦し続けている**: 結婚相談所で**お見合い戦歴はかなりある**。マッチングもデートもしているが、**交際まで至ったことが一度もない**。悲しい戦歴。「挑戦していないから無敗」という描写は**誤り**（脚本に使わない）。
- 30歳の童貞頑固オヤジ。ただし**高身長・高収入・高学歴・家柄良し**（横浜に実家、祖父は大学教授、父は大手メーカー部長、兄弟も高学歴）というギャップ付き。外見を磨いていないので「どこの田舎者か」という風体。
- 天然キャラで、悪意なくコントのように人をいらつかせたり、失敗したり、意図せず面白いことをする**愛すべきキャラ**（見下しの視点では書かない）。ときどきマジでやらかして周りがブチギレるが、やらかしがいちいち面白いので、それすら面白エピソードとして語り継がれている。
- **旧解釈の破棄（2026-07-08 ユーザー訂正）**: 初期テーマ「投了癖（負ける前に自分から投げる）」は**誤り**。実際は真逆で、諦めが悪い。内なる敵の正体は「**頑固・聞かない・一人で背負う**」。リワークは実装済み（設計の経緯は git 履歴の `story_rework_stubborn.md`）。

### ミーム運用

- ネットミームは**直球OK**（語録ほぼ原文で使ってよい）。なんJ語・淫夢語録・ビリー語録・「東大医学部頭悪くないか！？お前が正しい根拠を言え」・宮崎駿「極めてなにか生命に対する侮辱を感じます」等はみんなに刺さる実績あり。
- ただし**山場のシリアス区間だけは外す**（最終決戦の芯、エピローグの静かな箇所）。バカゲー×シリアスの二層構造を守るためのルール。

### 保持必須の内輪ネタ（正典）

1. **「にょ」**: S口が「アラスカ」で「すまん」を「**すまにょ**」と誤記したのが起源。ゲームでは先輩の語尾だが、**起源が S口本人の発言である点が重要**。エピローグで澤口が「すまにょ」と言うのはこの回収（実装済み）。先輩の「にょ」は短くドライに保つ（長台詞＋にょ連発は禁）。**先輩の第一人称も「にょ」**（例:「にょの心に入ってくるなにょ！」。「俺」は使わない。2026-07-14 ユーザー指示）。**先輩は説教しない**（2026-07-13 ユーザー指示）: 横着な行動・小さな損得・相手への短い反応で人物を見せる。格言を自分で撤回する定型にはしない。芯の場面は行動で締める。
2. **「けど、けれどね、私にも、寂しいときが、あるのです。」**: S口が引っかかったマッチングアプリの**サクラアカウントのプロフィール文**（**原文ママ厳守・一字も改変禁止**）。ユーザー評「お前はミコラーシュか」。S3 サクラ子機→撃破後に配置済み。
3. **「アラスカ」**: LINE グループ名そのもの。エピローグの未読通知（39件＝実装済み）など、現実に戻る場面の小ネタ。

### 変更時のルール

- 正典ネタ（上記3点）を削る・改変する変更は、ユーザー確認なしに行わない。
- 新しい内輪ネタの追加はユーザー提供が前提。**モデル人物に関する設定をエージェントが創作して足さない**。
- **意図的に残した「投了」表現**（機械的に消さないこと）: 藤井竜王の「盤上でしたら、最善手は投了です」（将棋用語としての形勢判断）／ゲームオーバーの「ここで投げるなにょ／……あと5分」（先延ばしギャグ）。
- 本書と `src/story/script.py` は相互同期。どちらかを変えたら、同じPRでもう片方へ反映する。

## 2. ログライン・登場人物

### ログライン

インフルエンザで高熱にうなされた澤口修平が、喋る薬・カロナール先輩と一夜を共にする。横着な先輩を助けた小さな借りが、ブラックホールでの救出につながる。最後は澤口自身が助けを求め、二人で踏ん張り、自分の一撃で頑固王を倒す。

- トーン: 内輪ネタのバカゲームと、不器用な相棒同士の話。実在人物の未提供の逸話は増やさない。
- 中心テーマ: 頑固さは一晩で消えない。それでも聞き直し、頼む行動はできる。先輩は人生を解決しない。
- 伏線: 「朝に殻が溶けても効き目は残る」「解熱圧には反動と消耗がある」「一個の貸し借り」「寝床を空ける」。
- 参考資料: [『ヤニねこ』参考調査](research/yanineko-reference.md)。原作設定・演者の解釈・本作の創作を区別する。

### 澤口修平

31歳・独身・大手メーカー勤務。将棋有段者、英検2級、物理学修士。頭でっかちで、意地を張ると周囲の声が入らなくなる。
先輩の不始末を助け、助けられ、最後は自分から頼る。戦闘中の自機と左側の立ち絵は右向き graphic/characters/sawaguchi_right.png。
頑固王は元の左向き sawaguchi.png を使い、向き合う。

### カロナール先輩

- 主軸は『ヤニねこ』のヤニねこ。普段は横着で、休む場所と手柄にうるさい。都合のよい時だけ先輩ぶる。第一人称・語尾は本作正典の「にょ」。
- ヤクねこ由来の不穏さはごく少数の言動にとどめる。薬物経験を確定したり、薬物の対処法を説明したりしない。
- 人生論を講義する役ではない。言うことが見つからない時には、一緒に座っている。
- **解熱圧**は発熱夢の架空能力。力を一方向に放つと本人には逆向きの反動があり、強いほど消耗する。序盤で横着に使って澤口に掴んでもらう。
- ブラックホールでは残る力を全部使い、澤口を遠く外へ押し出す。自分が落ちることを承知した救出。
- 最終戦で顕現するのは残った効き目。「薬効最大」はその残効を集中した最後の支援であり、救出の消耗を帳消しにしない。
- 戦闘は右向き karonaru.png / karonaru_max.png。右側の立ち絵は左向き karonaru_left.png / karonaru_max_left.png。
- エピローグは現実。薬から返事はない。

### ボス

章の順に、悪寒大王インフルX／情報汚染超人野獣ブロリー（超サイヤ人ブロリー）／婚活要塞マッチング・ゼロ／棋理の化身 藤井竜王・赤眼の真・藤井四段・頑固王サワグチ。
最後に対峙するのは澤口の「聞かない・一人で背負う」癖。倒すのは澤口自身。
ブロリーは透過の全身ドット絵を通常形態・強化形態で共用し、強化時にはオーラを加える。

## 3. ゲーム構造・UI・演出の共通言語

### 進行の骨格（STORY_BEATS の並び）
```
起動 → 注意書き（SCENE 000）→ タイトル →（ゲームスタート）→ プロローグ会話（発熱夢＋ブリーフィング）
  →〔初回のみ〕対話型チュートリアル「準備運動」
  → 第一章プレイ → ボス戦（悪寒大王インフルX）
  → 幕間 1→2 → 第二章プレイ → ボス戦（ブロリー→超サイヤ人ブロリー）
  → 幕間 2→3 → 第三章プレイ → ボス戦（マッチング・ゼロ）
  → 【承認欲求ブラックホール】（先輩の自己犠牲＝喪失）
  → 幕間 3→4（先輩不在）→ 第四章プレイ
  → ラスボス戦：藤井竜王 Form1 → 赤眼の真・藤井四段 Form2
     → 頑固王サワグチ Form3（フェイクアウト→必至宣言→先輩復帰→「先輩に頼る」操作→抗反芻→本人の新しい射撃で終局）
  → エピローグ（朝）→ ゲームクリア → エンドロール → ポストクレジット
```

### 会話パネルの種別（見分け）
- **全画面カットシーン**（プロローグ・幕間・エピローグ）: 立ち絵＋タイプライター表示、ENTERで送り。
- **戦闘中パネル**（画面下・顔アイコン付き・固定2行サイズ。体幹ゲージ／ボスHPバーには重ならない位置）:
  - 赤枠＝ボス登場セリフ（ENTER送り・戦闘前）
  - 紫枠（**会話カットイン**）＝戦闘中の会話ビート（各ボスの中盤会話・形態遷移直後・ラスボス中間）。**戦闘を停止して ENTER 送り**で読ませる
  - 紫枠（**単発バーク**）＝ビリー語録・サクラの一言・熱暴走の先輩ツッコミ。自動送り・戦闘継続
  - 青枠＝撃破後・味方寄り（ENTER送り）
- **中央バナー**: 章名／ALERT／BOSS名／FIGHT!／覚醒・必至宣言 等のシステム表示。

### 中央バナー・演出の一覧
- **章名バナー**（3秒）: 例「第一章：発熱回廊」。
- **ALERT**（2秒）: `！！ALERT！！` 赤点滅＋画面赤フラッシュ。`【音】SE_ALERT`。
- **BOSS名バナー**（2.5秒）: `── BOSS ──` ＋ボス名。`【音】ボス戦BGMへ切替`。
- **FIGHT!**（1.2秒）: `【音】fight.wav`。以後戦闘開始。
- 形態遷移・最終決戦の専用バナー: **覚醒／TRUE FINAL BOSS／必至宣言／薬効発現／HP全回復／必至・終局／LAST CHANCE**（各シーンで後述）。

### fx 語彙（カットシーンのページに付く演出タグ）
`shake`＝画面シェイク／`red_noise`＝赤いノイズ（発熱）／`white_particle`＝白い光の粒子（先輩の顕現・溶解）／`glitch`＝グリッチ（SNS汚染の予兆）／`blackhole`＝重い揺れ＋渦。

### プレイヤー武器・強化（グラディウス式スロット）
- **上段（自機）**: MAIN UP（RAPID1→RAPID2→WIDE→WIDE+。**MEDIC**は終盤の物語報酬）／HOMING（と金＝将棋の成り駒がホーミング）／LASER（押して発射・離して停止する連続レーザー）／SPEED。
- **下段（先輩）**: HP UP／解熱弾／補給／マグネット。
- **アイテム**: `W`（黄）＝ウェポン在庫+1（取得後、選択画面で強化先を選ぶ）／`+`（緑）＝HP回復。

### 道中の敵ロスター（各章に配置・`data/stages/*.json`）
バイキン（直進）／タケシ（波打ち接近）／パチェモン／クローラー（地形を這う）／砲台（turret）／ブロリー系雑魚（接近して高速突進・粒子砲）／咳スプレー（弾幕）／大型残骸（割れて破片化）／胞子分裂体（倒すと分裂）／**ビリー**（各章1体の中ボス格・撃破でウェポン報酬。登場/撃破時にガチムチ語録バークをランダム表示——登場:「ん？」「いいゾ〜これ」「やりますねぇ！」「ファッ！？」／撃破:「お前のことが好きだったんだよ！」「あーもうめちゃくちゃだよ」＋SE「アｯー♂」）。破壊可能ゲート／ウェポンゲート／ボスゲート（到達でボス戦へ）。

### ボスの攻略
- **counter（大技後の反撃）**: ブロリー両形態。予告の射線から逃れ、大技が消えた後の2.4秒に戻って撃つ。防御中20%、隙には2倍のダメージ。体幹ゲージなし。
- **shield（周期シールド＋反撃）**: シールド展開中は無敵＋強攻撃、解除中(6秒)は通常ダメージが通る。体幹による追加軽減は重ねない。→ 悪寒大王インフルX／藤井竜王Form1。体幹はシールド解除中のみ削れる。
- **weakpoint（装甲＋弱点露出）**: 体幹がある間は被ダメ無効、削り切ると弱点露出(2.6秒)で**被ダメ2倍**。→ 赤眼の真・藤井四段Form2。
- **turrets（砲台要塞連動）**: 砲台を召喚、健在中は本体ほぼ無敵、**全砲台撃破でスタン(2.6秒・被ダメ2倍)。1組目の後は再召喚、2組目を倒すと盾が完全に壊れ、落石攻撃を使う本体戦へ移る**。→ マッチング・ゼロ。子機は**サクラ**（マッチングアプリ風の円形プロフィールアイコン、ラベル「サクラ xN」）。**本体の陰に1機**が隠れ、最初はレーザーだけが盾を貫ける。**手前の2機を倒すと奥の盾が解除され、0.65秒かけて本体の前へ移動する**。紫の盾が消え、通常弾でも倒せるため、レーザーを未取得・喪失していても攻略できる。解除時は緑の粒子と「奥の子機：盾解除」を表示する。**最後の1機を撃破した瞬間にサクラ「けど、けれどね……」**（撃破後のフル文への前フリ）。

### 戦闘システム（反撃の隙・体幹・体温・症状悪化）
- **体幹ゲージ**: ボスHPバー直上の金色バー。削り切ると**ダウン**＝「反撃！」と「反撃の隙・ダメージ増」（**S4のみポップアップ「王手！！」＋駒音**）。被ダメ2倍の撃ち込みチャンス。レーザーが最も削れる。Form3（頑固王）は対象外。1プレイ中の初回ダウン時のみ、同行・活動中の先輩が「動きが止まったにょ。／今ならダメージ2倍。撃ち込めにょ！」と説明する。先輩が不在・撤退中ならSYSが「敵の動きが止まると反撃の隙。／この間はダメージ2倍。攻撃のチャンス。」と案内する。
- **体温計（HUD）**: レーザーを発射・継続すると36.5→39.9℃へ上昇、上限で**「熱暴走！！」**＝2.4秒レーザーを停止。通常射撃・ホーミングは継続でき、成長した通常弾へ切り替えて冷やせる。同行・活動中の先輩だけが、ステージにつき1回バークを発する（「撃ちすぎだにょ。用法・用量にょ」／「熱は下げるもんだにょ」／「効きすぎは、こわいにょ。……経験談だにょ」からランダム）。不在・撤退中は台詞を出さず、熱暴走の表示と効果音だけで伝える。**先輩の解熱弾Lvで冷却が速くなる**。ボスダウン中は冷却2倍。
- **症状悪化**: ボス戦が長引くと攻撃間隔が最大1.4倍まで圧縮（Form3対象外）。待ち戦法への対抗。
