# やりごたえと強化配分の再設計

## 終了条件
- 速度・レーザー・追尾を含む複数の配分で攻略が成立する。
- 単純な回避より、連続攻撃を読んだ位置取りで安定性が上がる。
- 各章の道中難所・ボス・最終決戦で、死亡後に同じ条件へ短時間で戻れる。
- 全章進行・強化総量・回復上限・再取得による増殖を検証する。

## 方針
- 初期速度140、速度強化175/210/245、レーザーBを継続。
- 道中の確定強化を3/2/2/3、1〜3章のボス撃破で各1。全体13ポイント。
- レーザー・追尾弾を初めから選択可能。先輩のポイントは強化2個につき1。
- 通常弾20ダメージ、接触22。補給は区間あたり合計15/25/35回復。
- 難所とボス前に回復・再挑戦地点。攻撃は順番を読んで避ける構成。
