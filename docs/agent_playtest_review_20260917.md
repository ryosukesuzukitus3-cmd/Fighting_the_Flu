v2と短い手動操作・再生の対象版は `ce4de36535b39506e5d9e328abf0bdcea4b78e2c`。この版の実行結果は全テスト436件成功、CIのPython 3.11 / 3.13成功。その後の追加修正まで含めた最終版の全体結果は保留する。

## 1. 検証方法と、分かることの範囲

| 方法 | 入力・観測 | 確認できる範囲と制限 |
|---|---|---|
| 画面を見た手動判断 | エージェントが完成画面を見て、移動・射撃・決定などの通常操作をフレーム指定で送信 | 入力の反映、表示、ポーズ、再開を確認。ツールの思考中は時間が止まるため、リアルタイムの人間の反応速度を再現しない |
| 全章診断ボット | 敵・弾・地形・自機などの内部座標を読み、原則12フレーム（0.2秒）以上の間隔で通常入力を選択 | 同じ条件での進行と失敗箇所を記録できる。画面だけを読んで遊ぶプレイヤーより多くの情報があり、人間向け難度の合否には使わない |
| 準備済みの場面別試験 | ボス形態・HP・配置などを試験用に準備し、その後の処理を確認 | 特定条件の不具合と修正効果を分離して検証。通常の入口からそこまで到達した証拠にはならない |
| 以前の全章手動確認 | 元版 `96c0427` を画面操作し、第1章の死亡後からF1無敵を使用 | 会話・章間・エンディングの到達経路を確認した過去の記録。通常難度でのクリアでも、今回の確定版の完走でもない |

検証モードと通常起動は `Game.step` の更新・描画処理を共有する。検証モードは1/60秒刻みで進み、場面や会話の境界で停止する。観測・画像保存だけでは追加のゲーム時間や乱数を進めない。押下と解放を記録し、再生時にフレーム・状態・画像の要約値を比較する。

検証モードではデバッグ操作を無効にし、ボットにHP回復・装備付与・瞬間移動・強制撃破などの操作は提供しない。保存先は各証拠フォルダ内の専用ユーザーデータに隔離した。記録の `rule_overrides: []` はゲームルールの上書きがないことを意味し、内部座標の観測や無制限の判断時間がないことは意味しない。

### v1失敗後の変更とv2再走

失敗を分析し、ゲーム側とボット側を分けて修正した。

- **ボット側**：太いビームの中で全方向の危険度が同点になり、静止を選び続ける問題を修正。危険範囲から出るまでの距離も判断に使う。
- **ゲーム側**：ブロリーが予告後も上下に自機を追い、予告を見て避けた先へ撃つ挙動を修正。予告中のY座標を固定し、通常・強化個体の発射猶予を0.82秒から0.95秒へ延ばした。
- **ボットの停止・成功判定**：取得可能な強化がない場合の強化画面ループを防止。勝利画面到達 `victory_reached` と、クレジット後のタイトル帰還 `completed` を分離。最後の入力で実行予算に達しても、タイトルに帰還済みなら完了を記録する。
- **再現情報**：確定版で再開始し、`session.json` に加えて `source-fingerprints.json` にソースのハッシュを保存する。

ブロリーの単体試験は、他の敵・地形・自動スポーンを除いた開けた場所で実施した。速度強化0、HP100、無敵なしで、警告開始から12フレーム待ち、上または下へ移動する同じ入力を比較した。

| 強化個体への入力 | 修正前：初弾後 / 砲撃終了HP | 修正後：初弾後 / 砲撃終了HP |
|---|---:|---:|
| 上へ回避 | 84 / 68 | 100 / 100 |
| 下へ回避 | 84 / 84 | 100 / 100 |
| 静止する対照条件 | 84 / 68 | 84 / 68 |

通常個体も含めた6条件が修正後に成功した。ビーム高さ286、強化個体のダメージ16、砲撃継続1.3秒は維持している。警告の生成時点を反応待ちの起点にしているため、人間が警告を見つけるまでの時間は測っていない。後続の本体突進、地形や複数の敵が重なる難度もこの試験の範囲外。

Broly修正前に開始して中止した走行は `seed1-v2-pre-broly-fix/` に分離した。現在のv2は `seed1-v2/` であり、両者を合算しない。

### v2中の追加調査：透明部分の被弾と画面外への回避

ブロリー砲の645×286の画像に含まれる透明余白と自機の被弾枠が重なると、交差箇所の画素のアルファ値が全て0でもHPが100から88へ減ることを再現した。`LaserBeamSprite` は現在の描画フレームの非透明画素を使うマスク判定へ変更した。通常弾の従来の矩形判定、ビームの幅・威力・寿命は維持している。実行結果は専用11件と関連12件、計23テスト成功。証拠の保存先は最終統合時に追記する。

ボットにも、ビームから最短で出られる方向として画面外を選び、下端で止まったまま被弾する欠点が見つかった。実際に移動できる出口だけを評価する修正を進めている。**このボット修正の完了・検証結果はまだ記録しない。** v2は第4章で1回死亡後、修正を反映するため正常停止を依頼した。起動時の版での走行であり、追加修正の通し検証にはならない。修正を一つのコミットに固定し、v3全章走行と同版での全入力再生を行う予定である。
