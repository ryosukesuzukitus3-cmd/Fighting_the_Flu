## 1. 検証の方法と限界

| 方法 | 確認したもの | 証明しないもの |
|---|---|---|
| 画面を見た手動判断 | エージェントが画像を見て通常操作を選ぶ。移動・射撃・保持・ポーズ・押し直しを確認 | 判断中は時間が止まるため、人間のリアルタイム反応速度や通常難度の評価にはならない |
| 全章診断ボット | 内部の自機・敵・弾・地形座標を読み、通常の入力で進む。今回の無死亡完走はこの方法 | 画面だけから判断するプレイヤーより情報が多い。人間向け難度の合格判定や、全装備・全分岐の保証にはならない |
| 準備済みの場面別試験 | ボス形態・HP・配置などを準備し、特定の不具合と修正効果を比較 | その場面まで通常操作で到達した証拠にはならない |
| 以前の全章手動確認 | 元版 `96c0427` の会話・章間・エンディングに到達した過去の記録 | 第1章の死亡後からF1無敵を使用。今回の版や通常難度での完走ではない |

検証モードと通常起動は `Game.step` の更新・描画処理を共有する。検証では1/60秒刻みで入力を送り、場面や会話の境界で止める。観測・画像保存だけではゲーム時間や乱数を進めず、押下・解放と結果を記録する。再生では各入力後のフレーム・状態・画像の要約値を比較する。

ボットはデバッグ操作、HP回復、装備付与、瞬間移動、強制撃破などを行わない。装備や回復はゲーム内の通常処理で取得する。保存先は各実行の専用ユーザーデータへ隔離した。`rule_overrides: []` はゲームルールの上書きがないという意味であり、内部座標の観測や無制限の判断時間がないという意味ではない。

## 4. 検証ツールの改善と撃破後の追加修正

ボットでは、太いビームの中で静止を選び続ける問題、画面外や地形の向こうを出口に選ぶ問題、飛び飛びの予測時点の間に弾と交差する問題を修正した。反射済みの無害弾を回避対象から外し、被弾直前の位置・入力・弾の速度も保存する。これらの理由でゲームの威力や難易度を下げてはいない。

取得可能な強化がない場合のメニューループも防止した。成功判定は勝利画面到達とタイトル帰還を分離し、例外・中止・再開回数切れを完走扱いしない。可視再生では、押下・解放を一組で送るtap入力の途中で閉じると、閉じた表示を再参照する例外とキー保持の残りがあった。終了後の追加処理を止め、送信予定と実際の保持キーを解放するよう修正。新規4件を含む関連22テストが27.26秒で成功し、最後の完成画面を保持して再生中止を返すことを確認した。

### 全章クリア後の修正版 `3445b2c`

全章クリア版では、ボス撃破後に通常の強化キーVが拒否されていた。ゲーム側に強化用の受付条件を設け、**非最終章の撃破会話終了後**は取得済み在庫を通常UIで使えるようにした。会話待ち・会話中・最終決戦後は受け付けず、選択中は移動と自動遷移タイマーを停止する。

ボット側も、取得済みの強化を選択し、残アイテムは通常のマグネット回収を待ち、回収と選択が済んだら右へ歩くよう変更した。最終決戦後は自動進行を待つ。戦闘中の回避方針は変更していない。

新規9テストと既存の関連テストが成功。準備済みの実GameSceneで、報酬回収→通常UI強化→右出口→リザルト・章間会話→第2章到達を確認した。会話待ち・最終決戦後の抑止も確認済み。

さらに `3445b2c` で、タイトルからv4の既存872コマンドを通常入力として送り、強化画面が開く直前まで結果が一致した。フレーム9,338で従来拒否されたV操作が受理され、自然取得した在庫を各1個使って自機の速度0→1、先輩の射撃0→1を選択。右へ進み、フレーム9,530でStageClearへ到達し、両方の強化の引き継ぎも一致した（終了コード0）。この追加確認は準備済み状態・ルール上書きなし。終了処理も修正した最終実装 `5e79d2f` で、この記録全892コマンドを再生し、9,530フレームまでフレーム・状態・画像が完全一致した（終了コード0）。
