# アクションの再設計・改善記録（2026-09-19）

## 目的と判断基準

少ない操作で、変な敵の攻撃を読み、位置取りで避け、反撃を決める。
内輪ネタの面白さと、予告・判定・入力の信頼性を別々に評価する。
クリアできることだけで完成としない。主要な攻撃を体験できるか、避けた後の
反撃に利点があるか、成長が気持ちよさを増すかを調べる。

## 修正ループ（進行中）

1. 基点 main 9078c49。専用 worktree / codex/action-core。
2. 実ゲームの Game.step を使う tools/combat_lab.py を作成。
   空のアリーナ・指定装備を準備後、通常キー・通常ダメージで戦う。
   原版2面、主砲4/レーザー3/追尾0、seed11、12フレーム判断：20.2秒、HP100。
   内部座標を読む診断であり、人の初見難度ではない。通常形態では反撃の
   窓が早期に開き、大技を十分に経験しないままHP段階が切り替わる。
3. 持ち駒の入力・報酬・在庫・HUDを撤去。コンボは得点だけの任意の遊び。
   レーザーは押して発射・離して停止へ。充填ゲージを撤去。
   入力・進行等の74項目中72成功、旧HUD引数と冷却の下限期待値を修正。
4. ブロリー両形態は大技の後隙で反撃する構造へ。体幹ゲージを撤去。
   連射1ダメージが防御倍率を丸めで無視していた問題を小数蓄積で修正。
   大技の射線・予告時間・発射後の停止を揃えて比較中。

## 検証の範囲

- combat_lab: 用意した場面の比較。通常の通しプレイとは区別する。
- agent-campaign: タイトルから通常入力で進む通し検証。後で実施する。
- stage_report: JSONの敵・報酬配置を座標順に報告。表示数は同時出現数ではない。
- 証拠: captures/action-core/。途中版の数値を最終値へ混ぜない。
