# アクションの再設計と検証記録（2026-09-19）

## 決めた核

**攻撃を読んで射線を作り、短い隙に撃ち込む。**

内輪ネタの funny さと、入力・予告・判定の信頼性を別々に評価する。
体温は撃ち込みと休止にメリハリを付ける補助で、管理そのものを主役にしない。
「避けた」だけでなく、攻撃が届く位置に戻れることを上達の中心に置く。

## 実装した内容

1. **持ち駒を廃止**。取得・所持枠・発射キー・設定・HUDを撤去。コンボは得点だけに関わる。
2. **レーザーを単純化**。押して発射、離して即座に攻撃停止。充填・残弾ゲージをなくし、体温に一本化。
   通常弾は過熱中も使用可能。ボスの反撃時間中はレーザーを撃ちながら冷却できる。
3. **ブロリーを基準に再設計**。両形態とも大技の後に2.4秒の反撃時間。
   防御中20%、隙は2倍のダメージ。体幹ゲージを外し、予告位置と発射位置を一致させる。
   通常予告0.95秒、超サイヤ人1.7秒。後者は260px幅・吸引125px/秒で、本編の地形に退避場所を残す。
   一つのビームによる被弾は1回。ビーム自体は接触後も消えない。
4. **他ボスと道中へ適用**。
   - 1面は扇形→突進、4面は駒の隊列→成り駒・駒打ちへ整理。
   - 1面・藤井Form1はシールド解除中に通常ダメージが通る。体幹による二重の軽減をやめる。
   - 3面は子機を2組倒すと盾が完全に壊れ、落石を使う本体戦へ移る。レーザーなしでも先へ進める。
   - 道中は大型敵と砲台の重複を減らし、遭遇ごとに主役の攻撃を読み取れる配置へ調整。
5. **成長を調整**。主砲の中央弾を保つ。レーザーは段階ごとに幅・連続ダメージを改善。
   追尾弾は1発4→2ダメージにして補助役へ。速度は5段階・最大2倍から、3段階・最大1.36倍へ。
   古い速度強化データは新しい上限へ収める。練習場にはレーザーの発射・冷却を実際に試す段階を追加。

## 確認→修正で分かったこと

| 発見 | 判断・修正 | 再確認 |
|---|---|---|
| 旧2面は大技を十分経験しないまま形態が進む | 大技後の隙を攻略の中心にする | 予告・発射・反撃を繰り返して撃破 |
| 一般的な温度管理だけの操作は、撃ちっぱなしより遅い | 温存だけを正解にせず、隙に位置を合わせる操作へ | 下記の比較。反撃位置に戻る速さで差が変わる |
| 1ダメージの連射が丸めにより防御倍率を無視する | 小数分を蓄積して正しい軽減率を保つ | 10回の1ダメージで防御中2、隙なら20を確認 |
| 1面の弱い主砲はシールドと体幹の軽減が重なり長期化 | シールドが開いたら通常ダメージを通す | 初期主砲のみでも86.2秒で撃破 |
| 3面の無防備な再召喚待ちをなくすと、弱装備で再召喚が長く続く | 2組を倒したら本体戦へ進む段階制へ | 主砲Lv2・レーザーなしでも117.8秒で撃破 |
| 空の検証場で勝てても、本編2面の床・天井と吸引で連続被弾 | 本編ボス部屋を検証場へ再現。吸引も予測し、退避幅・予告・重複被弾を修正 | 地形付き2面でHP100のまま撃破 |
| 0.2秒の移動を毎回押し切る自動操作は、小さい安全地帯に止まれない | 判断時に短い押下と解放時刻まで計画する | 判断間隔は0.2秒のまま、地形を越えず退避できる |
| 練習場へ新段階を追加しても更新経路へ入っていなかった | 通常入力からレーザー練習を通る経路を修正 | 発射→解放・冷却→人形戦への実入力テストが成功 |

## ボス比較の結果

`combat-lab` は場面・装備を準備してから、実際のGame.step・キー入力・当たり判定で戦う。
途中の回復付与・無敵化・強制命中は行わない。内部の位置や状態を読む診断であり、人間の初見難度の測定ではない。
戦闘秒数は入力区間の開始モードで集計するため、境界には判断間隔程度の誤差がある。

## 環境整備

- `combat-lab`: 空アリーナ／本編ボス部屋、装備・入力方針の比較、被弾画像、移動候補、入力・ソース指紋を保存。
- `stage-report`: 人間向け設計ツールと同じ章JSONから、座標順の遭遇・確定報酬を読める形にする。
- 操作は子機への集中、吸引の予測、移動キーの途中解放に対応。ゲームの吸引計算は共通の関数を使う。
- 自動試行は毎回のPNG上書きだけを省略。全フレームの更新・描画・乱数・画像ハッシュは維持。
  画像保存あり／なしで、実戦930記録のゲーム状態一致と、専用テストで描画回数・状態・画像ハッシュ一致を確認。
- `stop.request` による記録付き停止、撃破以外の終了コード、章データを含むSHA-256で再現性を補強。

## 最終確認

- ゲーム・操作ツールの対象コミット: **775638096a2db42858920fa4a9be08677f335833**。
- ローカル自動テスト: **519件成功**。整合性チェック24項目、文書生成チェック、構文チェックも成功。
- `campaign-v3`: 同コミットのクリーンな作業場所から、タイトル→練習→全4章→ブラックホール→最終決戦・最後の一撃→エンディング→クレジット→タイトル復帰まで完了。
- 無敵化・装備付与・回復付与・強制撃破なし。ゲームオーバー0回。4,577回の判断、54,925フレーム（自動入力での換算15分15秒）。スコア135,490、撃破334。
- 通常被弾は1面1回、2面0回、3面2回、4面5回。最終決戦の必至宣言によるHP減少9記録は、台詞中の物語演出として分ける。
- ボス到達時の装備は、1面=主砲2/レーザー1、2面=主砲4/レーザー3/追尾1、3面=主砲4/レーザー3/追尾4、4面=主砲4/レーザー4/追尾7。道中の取得と通常の強化画面だけで成長を確認。
- `campaign-summary.json` と `verification-manifest.json` に完走結果を保存。最終通しと表の地形付き4試行は、すべてゲーム・操作ツール・章JSONの指紋が最終ソースと一致。
- 人間による初見の笑い、連続した手触り・音の体感は自動操作の数値で保証しない。上記は進行・操作・攻略の成立と画像確認の証拠。


## 今回の終了判断

操作の削減、予告と判定の整合、反撃を狙う利点、弱装備での進行、章ごとの攻撃の違い、
道中から育てた装備での全章クリアを確認できたため、今回の改善ループを終了する。
体温を主役の管理ゲームに戻さず、今後も「射線を作って撃ち込めるか」を変更の判断基準にする。
