# UI全般の見直し（2026-09-16）

## 方針

ユーザーの「UI全般見直してください」に基づき、タイトルから戦闘・会話・結果まで、情報の優先順位と操作案内を揃えた。
濃紺のパネル、金色の選択、ミント色の正常状態、赤色の危険状態を基本とし、選択は色だけでなく枠・左端の線・三角印でも示す。
本文と操作欄を分け、長いキー名・大きな数値・長い台詞でも重ならない表示を優先した。

## 対応

| 領域 | 見つかった問題 | 修正 |
|---|---|---|
| タイトル | 選択が下線だけで弱く、下端の操作案内が暗く開発用表示と重なる | 選択枠・三角印・各項目の説明を追加。メニュー名を日本語で整理し、操作案内を共通欄へ |
| 共通メニュー | 背景の大きな円模様が強く、長い操作キーでフッターがはみ出す | 背景を抑えてキャッシュ。文字幅に応じて操作案内を折り返す |
| 設定 | 音量・移動・戦闘・メニュー操作が長い1列に混在する | 音量・ゲーム操作・メニュー操作の3分類。全14項目がスクロールなしで見える |
| キー変更 | 変更対象が分かりにくく、初期化が即実行。Escを決定にすると戻ると衝突する | 操作名・現在キー・完了通知、初期化の確認を追加。決定にEscを禁止し古い設定も修復 |
| 戦闘HUD | スコアと空装備の説明が目立ち、HP・体温と強化在庫の優先度が低い | 上端88pxを維持。HP・体温を優先し、使える強化と持駒だけを強調。熱暴走中のレーザーを「熱で停止」と表示 |
| 先輩の強化在庫 | 自機在庫が0だと先輩の在庫があっても強化キーが見えなくなる | 両方の在庫をHUDに渡し、どちらかに在庫があれば案内する |
| ポーズ | 選択枠が文字に食い込み、再開とタイトルへ戻る意味が曖昧 | 日本語見出し、十分な行高、選択肢ごとの補足を追加 |
| 強化 | 自機・先輩・確定の段階と未解放理由が読みにくい | 3段階の案内、選択済み表示、解放条件、確定内容を表示。選択漏れがあれば未選択の系統へ戻す |
| 会話 | プロローグ13/31などの長文が枠外や操作欄へ出る | 本文サイズを維持して枠を上へ拡張。本文・話者・ページ数・操作欄を分離 |
| 明るい背景の会話 | エピローグの白い話者名が背景へ埋もれる | 紺色パネルでコントラストを確保。話者色のアクセントは維持 |
| 練習 | 操作案内が矢印固定で、何を終えたか分からない | 段階1/3〜3/3、設定済みキー、移動の達成・発射数・人形HPを表示。射撃キーと衝突しない終了操作も案内 |
| ハイスコア | 空白で列を揃えており、右端の見出しが枠外に出る | 独立した列幅、桁区切り、名前の省略、空データ案内を追加 |
| プレイ記録 | 英語見出し・点だけのページ表示、到達率を「生存率」と表示 | 日本語の3タブと意味が正しい見出し、読みやすい表、記録なしの案内へ |
| ゲームオーバー | 選択枠と本文が重なり、継続・新規開始の違いが不明瞭 | 選択肢と補足を分け、有給消費・HP回復・章開始装備・初期化対象を表示 |
| 章クリア・ゲームクリア | 数値や案内の優先順位が弱く、大きな数値が侵入し得る | ラベルと値を分離し、日本語の見出し・次の操作を明示 |
| 注意書き・スタッフロール | 低い文字コントラスト、英語の操作案内、強すぎる背景線 | 正典の本文を維持し、読みやすい配色と日本語操作案内へ。背景線は通常の透明度で合成 |
| ブラックホール | ノイズの透明度が加算描画で効かず、本文・操作欄へ白線が重なる | 通常の透明度で合成し、動的に広がる本文領域だけへノイズを限定 |

## 検証

- 基準: main `7b5f685`。専用 `codex/ui-review` で作業。
- Windows / Python 3.14.3 / pygame-ce 2.5.8。統合時の全366件成功（92.87秒）、整合性24/24・構文・生成資料・差分チェック成功。
- ブラックホールの追加修正は3件の回帰ケースを含む関連15件成功（1.98秒）。最終コミットに対するCIのPython 3.11・3.13の結果はPRと検証成果物に記録する。
- タイトル・設定の各分類・キー変更・初期化、HUD・ポーズ・強化、全台本の会話枠、練習、各結果画面、統計3ページ、空データを実際の描画コードで確認。長い名前・12桁スコア・長い操作キーも確認した。
- 設定画面はTabを決定または戻るに割り当てても、矢印だけで全14項目へ到達できることを確認した。
- 実ウインドウを選択・アクティブ化し `focused=true` を確認。`tools/run.py playtest` の入力補助を使い、通常のキーイベントで次を操作した。
  - タイトル→設定、分類切替、ショットZ→F、キー変更取消、選択位置を保ったタイトル復帰。
  - 練習で上下左右の移動、設定済みFによる6発の射撃、人形との戦闘と被弾後の結果表示、練習終了。
  - 本編の導入を表示し、画面にある省略操作で第一章へ。ポーズ→設定→復帰→再開→再ポーズを確認。設定中はHP25のまま維持。
  - 初期化確認の「やめる」と「初期化する」をそれぞれ実行。確認用の変更キーは初期値へ戻し、ゲームを通常終了。
- 通常プレイで全章を完走した検証ではない。後半の会話・終局・結果画面は状態を用意した描画確認と挙動テスト。今回のUI修正後のEXEは作成していない。

追加テストの作成途中には、入場中の自機を操作可能と扱ったケース、任意ライブラリ依存、ノイズ以外の揺れを含めた画像比較が失敗した。前提を実際の動作へ合わせ、標準pygameの画素比較と揺れ・点滅の固定で解消した。
