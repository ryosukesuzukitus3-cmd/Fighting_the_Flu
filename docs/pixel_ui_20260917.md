# 承認済みドットUIへの反映（2026-09-17）

## 方針と対応

ユーザーが確認した6枚の画像案（2026-09-16）を実装へ反映した。ゲームUIをドット文字・余白・少数の差し色で組み立て、PR #128で増やした囲みや装飾を減らした。画像案は見た目の基準として使い、生成画像による背景・キャラクターの置換は行っていない。

| 対象 | 反映内容 |
|---|---|
| タイトル | PR #128前の暖色背景・中央5メニュー・選択下線へ復元。開発用ショートカット文字を外し、下端の操作案内を読みやすくした |
| 強化 | 外枠・8個のカード・確定ボタンの枠を撤去。自機と先輩を余白で分離し、コーラルのカーソルとミント色の「選択済み」で現在位置と確定候補を区別 |
| 一時停止 | 中央の枠・選択行の囲みを撤去。暗くした戦闘画面に見出しと3項目を直接表示。タイトルへ戻る際の終了説明は維持 |
| 戦闘HUD | 背景パネル・列の縦線・強化の網掛けを撤去。背景上でも読める1pxの硬い文字影を付加 |
| ゲージ | HP・体温・レーザー・ボスHP・体幹は角丸と外枠をなくし、塗りと残量で表示。コンボ残時間・ボス装甲ゲージも合わせた |
| 会話 | 2pxの角ばった外枠ひとつ、話者名を内側へ移動。内部区切り線・現在/総数・最終ページ専用の案内を削除 |
| 設定 | 単色背景、左寄せ見出し、囲みなしの3分類・項目・キー・音量バー。キー変更と初期化も文字中心の画面へ |
| 補助画面 | ハイスコア・統計・章クリア・ゲームオーバー・ゲームクリア・注意書きの表罫線やカード背景を整理し共通配色へ統一 |

共通色とカーソルは `src/scenes/meta_ui.py` が持つ。タイトルは復元対象のため従来色を維持する。

## 維持した機能

- 設定の全項目、Tabを決定/戻るに割り当てた場合の矢印移動、キー変更の取消、確認してからの初期化、元の画面への復帰。
- 自機/先輩の在庫・解放条件・強化上限・選択の保留・確認してからの消費。
- HP・体温・熱暴走・装備・レーザー状態・有給・得点・持駒・ボス体幹の情報。
- 会話の台詞全文、ストーリーの26px本文、長文での枠の拡張、長い設定キーの折返し、ブラックホールの本文内ノイズ、文字送りと長押し/省略操作。
- 会話の総数は描画APIへ渡さない。内部のページ進行は維持し、通常会話・ボス会話・練習・ブラックホール・終局までヒントを揃える。

ストーリーの台詞、章構成、敵配置、ダメージ、武器数値は変更していない。
