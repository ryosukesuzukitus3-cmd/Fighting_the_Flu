# 画像・先輩の物語・救出演出の見直し（2026-09-19）

## 反映内容

- 澤口／先輩／薬効最大の左右向き画像を用意。反転は元画像の画素をそのまま水平反転し、描き直しによる顔の変化を避けた。
- 会話の左側は右向き澤口、右側は左向き先輩。自機と同行中の先輩はともに右向き。頑固王は左向きを維持。
- タケシ／パチェモンを輪郭の欠けない透過の顔画像へ、ブロリーを透過の全身画像へ差し替え。通常・強化敵とボスで実際の大きさを確認。既存の当たり判定キャンバスを維持した。
- ブラックホールは架空能力「解熱圧」で救出。光が集まり、左に放出され、澤口は画面外へ352px移動。先輩は反動で右へ進み、地平面へ落ちる。
- 光の一回の放出は会話送りで再発火しない。通常送り／長押し／連打／省略でも進行できる。別れの言葉は読了まで消えない。
- 先輩の人物像はヤニねこを主軸に再構成。説明や格言から、横着・小さな損得・不器用な気遣いへ。ヤクねこ由来は少数の不穏な言動に留めた。
- 出会いから朝までを「一個の貸し借り」「寝床を空ける」でつなぐ。朝に残る効き目を序盤に示し、再会の理由にした。最後の一撃は引き続き澤口自身の入力・攻撃で決まる。
- 原典の出典と自筆メモを [参考調査](research/yanineko-reference.md) に保存。全巻・全X投稿の網羅はしていない。
- [台本](story.md) は全391項目の台詞を実装と逐語同期。正典の「にょ」「すまにょ」「アラスカ」「39件」とサクラの固定文を保持。
- 追加画像の生成元・プロンプト・ハッシュを data/visual_asset_sources.json に記録し、ゲームのエンドクレジットを更新。
