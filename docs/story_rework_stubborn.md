# ストーリーリワーク設計: 投了癖 → 頑固王（2026-07-08）

> **背景**: ユーザー訂正（`docs/story_canon.md` の人物像参照）により、旧テーマ「投了癖＝負ける前に自分から投げる」はモデル人物像として誤りと判明。実際の S口 は真逆で、諦めが悪い（鳥人間サークルで最後まで残った側）。本書は置き換え設計の SSOT。実装が途中で止まっても、本書＋story_canon.md があれば後任（モデル・エージェント不問）が完遂できる。
>
> **実装状況**: 本書コミット時点で未実装。実装ブランチは `claude/story-stubborn-rework`（着手済みなら）。

## 1. 新テーマ

- **旧**: 内なる敵＝「負ける前に、自分から投げる声」。決め台詞「俺はまだ、投了していない」。
- **新**: 内なる敵＝「**聞かない・一人で背負う・変わらない声**」＝自分の頑固さ。
  - 根性は本物として**肯定**する（諦めの悪さはこの男の武器。ボスが「諦めろ」と攻めても**効かない**）。
  - 弱点は「人の声が入らない」こと: 助言がフィードバックされない（5回言われてやっと届く）、自分が思い込んだ役割への自分勝手な責任感、白黒思考、前提を疑わない。
  - バディ・アークとの接続が旧テーマより強くなる: 「先輩の助けを受け取る」＝**31年間一度も指さなかった手（人の手を借りる）を指す**ことが最終決戦の回収点。既存の演出シーケンス（フェイクアウト→勧告→先輩復帰→終局）は**構造変更なしで意味だけ差し替え可能**。
- 二層構造（バカゲー×シリアス）・「先輩は人生を解決しない、もう一手指す時間を作るだけ」・「朝には溶けて消える」は全て不変。

## 2. 最終ボスの再定義

| 項目 | 旧 | 新 |
|---|---|---|
| 名前（表示名） | 投了王サワグチ | **頑固王サワグチ** |
| 正体 | 傷つく前に投げさせる自己防衛の声 | **間違いを認めずに済むよう、お前を変えさせない声**。「変わらなければ、間違ってなかったことにできる。一度も答え合わせをしないから、一生正しい」 |
| 追い詰め方 | 投了勧告（詰みだ→HP1固定） | **必至宣言**（将棋用語「必至」＝何もしなければ受からない局面）。「逃げ道は一つある——人の手を借りるという一手。だがお前は、それだけは指さない」→ HP1固定 |
| 倒され方 | 「負ける可能性と今投げることは別だ」 | 先輩復帰＝**盤の外から来た一手を受け取る**。「すぐ変われないことと、聞かないことは、別だ」 |
| 再生ギミックの意味 | 後悔の反芻で再生 | **自己正当化の反芻**で再生（「その言い訳、何度目だ。繰り返すほど、俺は硬くなる」）。抗反芻フィールド名はそのまま流用可 |
| 弾幕の意味付け | 盤面崩壊 | 変更なし（ちゃぶ台返し＝頑固オヤジの技として意味が増す。wall_gap 系は「白か黒か、選べ」の白黒思考弾として台詞側で意味付け） |

将棋モチーフ（藤井竜王 Form1/2＝才能への引け目・過去の自分）は**ほぼ無傷で維持**。「投了」という単語自体は将棋用語として残ってよい（例: 藤井竜王の「盤上でしたら、最善手は投了です」は形勢判断の台詞なので残す）。**禁止なのは「S口には投げ癖がある」という人物規定**。
